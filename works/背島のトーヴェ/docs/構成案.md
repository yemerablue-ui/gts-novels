# 背島のトーヴェ — 構成案

## 一行紹介

三百キロメートルの女がうつ伏せに眠っている。その背中に町がある。潮の満ち引きは彼女の呼吸で、四十三年ぶりの寝返りが近づいている——十五歳の見習い予報士が、数字だけを頼りにその日を当てようとする話。

## 中核のアイデア

- **地形＝身体**。島は比喩ではなく、実際に一人の女性の背中である。
- **気象＝生理**。潮汐は呼吸、地熱は体温、地震は夢。観測とは、眠っている人の容体を読むことである。
- **災害＝寝返り**。悪意はない。ただ寝苦しいだけで、二百十一人が死ぬ。
- 主人公の武器は勇気でも力でもなく、**記録と数字**。

## 単位系

本文では **メートル法**（m / km / ℃ / 分・秒）で統一する。この世界の住人は地球人ではないが、換算を読者に強いる設計にはしない。
例外として、島の住人が日常で使う言い回しだけを残す。

| 語 | 意味 | 用例 |
|----|------|------|
| 里（り） | 約 4 km。徒歩の距離感 | 「南へ二里」 |
| 沈む／浮く | 潮が満ちる／引く | 「島が沈んでる」 |
| 度（ど） | 傾斜角。寝返り時の危険度指標 | 「十八度を超えたら外へ出るな」 |

数値は必ず具体値で書き、「約」「およそ」は付けない。観測の話だからである。

## トーヴェ

| 項目 | 値 |
|------|-----|
| 全長 | 300 km |
| 姿勢 | うつ伏せ。頭が北、足が南 |
| 海面上に出ている部分 | 背中のみ。肩甲骨〜腰の帯状部 |
| 陸地の実寸 | 長さ 210 km × 幅 40 km |
| 体温 | 36.6〜36.8℃（肌床で計測） |
| 呼吸周期 | 6 時間 20 分（平常時） |
| 呼吸による島の上下 | 振幅 11.2 m |
| 拍動 | 1 分あたり 34（肌床に耳をつけて数えられる。心臓は背中から 20 km ほど奥にあり、ヴェルナは「心音ではない」と言う） |
| 覚醒歴 | なし。記録のある千年間、一度も目を開けていない |

トーヴェが何者で、なぜここで眠っているのかは第一部では明かさない。住人にとっても未解決の問題であり、彼らはそれを問わないことで暮らしを成立させている。

## 背島（せじま）の地理

| 地名 | 位置 | 備考 |
|------|------|------|
| 背骨山脈 | 島の中央を南北に走る尾根 | 最高峰「七つ瘤」標高 1,940 m。第七胸椎 |
| 肩町（かたまち） | 左右の肩甲骨のあいだの窪地 | 人口 4,000 人。島唯一の町。予報所がある |
| 腰坂（こしざか） | 島の南部、くびれの段丘 | 畑作地帯。傾斜に強い |
| 髪浜（かみはま） | 北端。海に流れ出た髪 | 黒い海藻の森。「髪藻」を採る |
| 肌床（はだどこ） | 土が薄く、肌が露出した場所 | 土の厚さは 3〜80 m。崖や谷底に多い。温かい |
| 懐流（ふところながれ） | 島の西の海 | 海底を押さえる胸から湧く暖流。周囲より水温 +8.0℃。肩町の漁場のすべて |

産毛は一本の太さが人の腕ほどあり、海風に一斉に傾ぐ。住人はこれを「毛原（けはら）」と呼び、繊維を採って綱にする。

## 寝返り

数十年から百年に一度。所要時間は数時間。島は最大 30 度傾き、一部が水没し、一部が新たに海上へ出る。

**前回：四十三年前。死者二百十一人。**

### 前兆（教科書どおりの順番）

1. 呼吸周期の短縮（6 時間 20 分 → 16 分台）
2. 地熱の上昇
3. 鳥肌——丘陵が一夜で一斉に隆起する
4. 夢揺れ——微弱な地震の頻発
5. 懐流の水温変化

四十三年前は 1〜4 が揃ったのに 5 だけが動かず、当時の予報士長はそれを根拠に避難を六日待った。**今回は 5 が最初に動く。**順番が違う、という一点が第一話の恐怖であり、第一部全体の謎になる。

## 寝返り予報所

肩町の崖端に建つ木の櫓。職員は三人。

観測項目は四つだけ——**水位（呼吸）・肌床温度（体温）・傾斜・夢揺れ**。
予報所の記録は、外れた見立ても消さずに残す。「外れ方に癖があるから」（ヴェルナ）。

## 第一部「呼吸潮」構成（全 8 話予定）

| 話 | 題 | 内容 |
|----|----|------|
| 1 | 呼吸潮 | 日常の観測。呼吸周期 6:17:12、懐流 −0.4℃。夜、島が 40 秒間呼吸を止める |
| 2 | 外れ方の癖 | ヴェルナが四十三年前の記録を開く。順番の狂いをめぐる対立。町にはまだ言わない |
| 3 | 毛原の火 | 夢揺れ初観測。毛原で火災。避難路の下見 |
| 4 | 母のノート | ヨナの記録が予報所の公式記録と食い違う。セシが独自に拍を数えはじめる |
| 5 | 鳥肌 | 一夜で丘が隆起。町がついに気づく。父との衝突 |
| 6 | 六日 | ヴェルナが四十三年前に何を言い、誰に黙らされたかを語る |
| 7 | 傾斜十八度 | 避難。寝返りが始まる。カイが懐流へ出る |
| 8 | 瞼 | 寝返りは途中で止まる。トーヴェの瞼が動く |

## 文体

- 三人称、セシ視点に固定。
- 数字を情緒として扱う。「〇・四度」が恐ろしい、と読者に思わせるまで下地を敷いてから出す。
- 巨大さは全景ではなく**接触面**で描く。手のひら、耳、足の裏、浮子の目盛り。全身像は最後まで出さない。
- 説明は台詞に逃がさず、作業のなかに埋める。観測手順そのものが世界説明になるように書く。
- 一文は短く。長い文はここぞの一箇所だけ。
- 既刊『匣庭のジャステイル』の破調（——の多用）は継承するが、密度は半分に抑える。こちらは「冷たく、正確な」語り。
